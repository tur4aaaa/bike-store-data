# Bike Store Data Management

This project is a **bike store data management system** built using **Rust** and **SQL**.  
It allows you to manage customers, sellers, orders, and other related data through a server interface. You can view, add, and update data easily.

---

## Project Structure


---

## Features

- Manage **customers**, **sellers**, and **orders**
- View and update data through a server interface
- Rust backend with SQL database integration

---

## Requirements

- Rust >= 1.70
- SQL database (PostgreSQL, MySQL, etc.)
- Git

---

## How to Run

1. Clone the repository:

# Example for PostgreSQL
psql -U your_username -d your_database -f sql/database.sql

RUN THE RUST SERVER:
cargo run

Connect to the server to view and modify data.
